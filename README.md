# AI-Based Dropout Prediction System

## Overview

An AI-powered predictive analytics system developed to identify students at risk of dropping out using machine learning techniques.

The project analyzes academic and demographic factors to predict student retention and support early intervention strategies.

---

## Features

- Student dropout prediction
- Data preprocessing and cleaning
- Feature engineering
- Classification modeling
- Performance evaluation using Precision, Recall, and F1-score

---

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Jupyter Notebook

---

## Dataset

The model was trained on 1,500+ student records containing academic and behavioral attributes.

---

## Model Performance

- Accuracy: 89%
- F1 Score: 0.87
- Improved prediction performance through feature engineering and preprocessing techniques.
